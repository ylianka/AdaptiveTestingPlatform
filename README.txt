
KUnow — це веб-платформа для діагностики рівня знань учнів з інформатики, яка реалізує адаптивний підхід до тестування. Система автоматично змінює складність завдань залежно від відповідей користувача та забезпечує автоматичне оцінювання результатів.


# Основні можливості системи

- адаптивне тестування;
- автоматичне оцінювання відповідей;
- підтримка різних типів тестових завдань;
- статистика та діагностика результатів;
- ролі учня та вчителя;
- створення навчальних класів;
- реєстрація учнів у системі;
- аналіз успішності за темами;
- історія проходження тестів.


# Авторизація та ролі користувачів

Система підтримує авторизацію користувачів із розподілом ролей:

- teacher — створення тестів, керування класами, перегляд статистики;
- student — проходження тестування та перегляд результатів.


# Функціонал для вчителя

Вчитель може:

- створювати та редагувати тести;
- додавати питання різних типів;
- налаштовувати рівні складності;
- створювати навчальні класи;
- реєструвати учнів у системі;
- прикріплювати учнів до класів;
- переглядати результати тестування;
- аналізувати статистику успішності;
- переглядати діагностику результатів;
- онулювати результати тестування;
- керувати тестами та списком учнів.


# Функціонал для учня

Учень може:

- проходити адаптивне тестування;
- переглядати результати тестування;
- аналізувати власну успішність;
- переглядати історію спроб;
- отримувати статистику за темами;
- переглядати кількість набраних балів та рівень знань.


# Адаптивне тестування

## Логіка адаптивності

Система використовує чотири рівні складності:

- початковий;
- середній;
- достатній;
- високий.

Під час проходження тесту:

- правильна відповідь → перехід до складнішого питання;
- неправильна відповідь → перехід до простішого питання.

Наступне завдання підбирається з тієї ж теми відповідно до поточного рівня складності або найближчого доступного рівня.


# Система оцінювання

## Вагова модель балів

| Рівень     | Бали |
---------------------
| Початковий  | 3 |
| Середній    | 6 |
| Достатній   | 9 |
| Високий     | 12 |

Нарахування балів виконується лише за правильні відповіді.

## Формула переведення у 100-бальну систему

(набрані бали / максимальні можливі бали) × 100


# Типи тестових завдань

Система підтримує:

* один варіант відповіді;
* кілька правильних відповідей;
* встановлення відповідностей;
* відкрита відповідь;
* вибір за зображенням;
* порядок елементів;
* числова відповідь;
* так / ні;
* заповнення пропусків.


# Перевірка відповідей

Для кожного типу завдань реалізовано окрему логіку перевірки:

* порівняння ідентифікаторів відповідей;
* перевірка множини правильних відповідей;
* текстове порівняння з нормалізацією;
* числове порівняння з допустимою похибкою;
* перевірка відповідностей;
* перевірка порядку елементів.


# Діагностика та аналітика

Система формує статистику результатів тестування та дозволяє аналізувати:

* кількість відповідей;
* кількість правильних відповідей;
* бали за темами;
* середній результат за спробами проходження тесту.

Результати відображаються у вигляді:

* таблиць;
* карток статистики;
* прогрес-діаграм;
* графіків успішності.


# Структура даних

Основні сутності системи:

* користувачі;
* тести;
* питання;
* варіанти відповідей;
* спроби проходження;
* відповіді користувачів.

Для збереження даних використовується SQLite-база даних із зовнішніми ключами між таблицями.

# Швидкий запуск проєкту

## Встановлення

1. Встановіть Python 3.10 або новіший.
2. У каталозі проєкту виконайте:

pip install -r requirements.txt

3. Запустіть застосунок:

python app.py

4. Відкрийте у браузері:

http://127.0.0.1:5000
